คู่มือใช้งานระบบ PandaStar Oil

ระบบนี้แสดงเมนูไม่เท่ากันให้แต่ละคน ขึ้นอยู่กับ "ตำแหน่งงาน" ที่ผูกไว้กับบัญชีผู้ใช้ และสิทธิ์ 9 อย่างที่ตำแหน่งนั้นได้รับ (ดูและแก้ไขได้ที่หน้า "ตั้งค่า → จัดการสิทธิ์การใช้งาน" สำหรับผู้ดูแลระบบเท่านั้น) คู่มือนี้จึงจัดกลุ่มตามสิทธิ์ ไม่ใช่ตามเมนู — เลือกกลุ่มสิทธิ์ที่ตรงกับบัญชีของท่านทางด้านซ้าย หรือพิมพ์คำค้นหาเพื่อหาหน้าที่ต้องการโดยตรง

🔑 ข้อมูลทั่วไป (BasicData) ⚙️ ปฏิบัติงาน (OprerationData) 💰 การเงิน (FinancialData) 📊 รายงาน (ReportData) 🚐 รถเล็ก (SmallTruckData) ⛽ หน้าลาน (GasStationData) 🚚 พขร. (DriverData) 🛡️ ผู้ดูแลระบบ (AdminData)

คำนำ — ทำไมระบบถึงหน้าตาเป็นแบบนี้

🗄️ ระบบเดิมเป็นอย่างไร

ก่อนหน้านี้ระบบ PandaStar Oil ทั้งหมด (ทั้งหน้าเว็บและฐานข้อมูล) รันอยู่บน Firebase ของ Google — เก็บข้อมูลทุกอย่างไว้ใน Firebase Realtime Database ซึ่งเป็นฐานข้อมูลแบบ "ต้นไม้ JSON" ก้อนเดียวยักษ์ ๆ (ไม่ใช่ตารางแบบฐานข้อมูลทั่วไป) และใช้ Firebase Authentication จัดการระบบล็อกอิน โค้ดหน้าเว็บกับ ส่วนจัดการข้อมูลอยู่รวมเป็นโปรเจกต์เดียวกันทั้งหมด

🔄 ทำไมถึงเปลี่ยนมาใช้ระบบนี้

ระบบปัจจุบันย้ายฐานข้อมูลมาเป็น PostgreSQL (ฐานข้อมูลเชิงสัมพันธ์ / SQL แบบมาตรฐาน) รันผ่านเซิร์ฟเวอร์ backend แยกต่างหาก และแยกโค้ดหน้าเว็บ (frontend) ออกจากเซิร์ฟเวอร์ (backend) เป็นคนละโปรเจกต์กันชัดเจน ด้วยเหตุผลหลัก ๆ ดังนี้:

ประเด็นระบบเดิม (Firebase)ระบบปัจจุบัน (PostgreSQL)
ความสัมพันธ์ของข้อมูล ไม่มี foreign key จริง ต้องใช้ตัวหลอกแบบ "id:ชื่อ" ผูกไว้ในข้อความ (เช่น เลขลูกค้ารวมกับชื่อในช่องเดียว) เสี่ยงข้อมูลไม่ตรงกันโดยไม่รู้ตัว มี foreign key จริง เชื่อมตารางกันถูกต้องแน่นอน ลดบั๊กประเภท "จับคู่ข้อมูลผิดแถว" ที่เจอบ่อยตอนย้ายระบบ
รหัสอ้างอิงแต่ละแถว (Primary Key) ใช้เลข id หรือ key ของ Firebase ซึ่งซ้ำกันได้ข้ามชุดข้อมูล เสี่ยงข้อมูลทับกันถ้ารวมข้อมูลจากหลายแหล่ง ทุกแถวมี UUID เฉพาะตัวจริง ไม่มีทางซ้ำกัน ปลอดภัยกว่าเวลาต้องนำเข้า/รวมข้อมูล
รายงานสรุป/ยอดต่าง ๆ ต้องดึงข้อมูลก้อน JSON ทั้งหมดมาคำนวณเองฝั่งหน้าเว็บ ยิ่งข้อมูลเยอะยิ่งช้าและเสี่ยงคำนวณผิด ใช้คำสั่ง SQL คำนวณ/เชื่อมตารางที่ฐานข้อมูลได้โดยตรง แม่นยำและรองรับข้อมูลปริมาณมากได้ดีกว่า
สิทธิ์การใช้งาน พึ่งพาการซ่อนเมนูฝั่งหน้าเว็บเป็นหลัก ฝั่งเซิร์ฟเวอร์ตรวจสิทธิ์ซ้ำอีกชั้นสำหรับข้อมูลสำคัญ (เช่น การแก้ตำแหน่ง/สิทธิ์ ข้อมูลบริษัท) ต่อให้รู้ลิงก์ตรงก็เข้าไม่ได้ถ้าไม่มีสิทธิ์จริง
การสำรองข้อมูล ต้องเข้าไปกดสำรองผ่านหน้า Firebase Console เอง ระบบสำรองข้อมูลอัตโนมัติทุกวันในตัว (ดูหน้า "สำรองข้อมูล" ในหมวดผู้ดูแลระบบ)

พูดง่าย ๆ คือเปลี่ยนจาก "ที่เก็บข้อมูลก้อนเดียวไม่มีโครงสร้างตายตัว" มาเป็น "ฐานข้อมูลที่มีโครงสร้างชัดเจน ตรวจสอบได้ ปลอดภัยกว่า และรองรับการออกรายงานที่ซับซ้อนของกิจการได้ดีกว่าในระยะยาว"

📥 ถ้าต้องการข้อมูลล่าสุดจากระบบเดิม ต้อง import อะไรบ้าง

ระบบใหม่ไม่ได้เชื่อมต่อกับ Firebase ของระบบเดิมแบบอัตโนมัติ ถ้าระบบเดิมยังมีข้อมูลที่เกิดขึ้นใหม่ (เช่น ยังใช้คู่ขนานกันอยู่ช่วงเปลี่ยนผ่าน) แล้วต้องการดึงข้อมูลล่าสุดเข้ามาไว้ในระบบนี้ ให้ทำตามขั้นตอนนี้:

  1. เข้า Firebase Console (console.firebase.google.com) ของโปรเจกต์เดิม → เมนู Realtime Database → กดไอคอนจุดสามจุด (⋮) ที่มุมขวาบนของหน้าข้อมูล → เลือก "Export JSON" เพื่อดาวน์โหลดข้อมูลทั้งหมดของระบบเดิมออกมาเป็นไฟล์ .json ไฟล์เดียว
  2. เข้าสู่ระบบด้วยบัญชีที่มีสิทธิ์ ผู้ดูแลระบบ (AdminData) แล้วไปที่หน้า "เลือกเมนู" เลื่อนลงไปที่ กล่อง "เครื่องมือผู้ดูแลระบบ"
  3. เลือกปุ่มให้ถูกกับสถานการณ์ (สำคัญมาก เลือกผิดข้อมูลหายได้):
    • "เพิ่มข้อมูลใหม่ (ไม่ลบของเดิม)" — แนะนำสำหรับการใช้งานทั่วไป ใช้เมื่อระบบนี้มีข้อมูลจริง เกิดขึ้นแล้ว (ลูกค้าใหม่ ตั๋วใหม่ การโอนเงินใหม่ ฯลฯ) จะเพิ่มเฉพาะรายการที่ยังไม่มีในระบบนี้เท่านั้น ข้อมูลเดิมที่มีอยู่แล้วจะไม่ถูกแตะต้องหรือลบทิ้งเลย
    • "นำเข้าข้อมูล JSON (ทับข้อมูลเดิมทั้งหมด)" — ใช้เฉพาะตอนตั้งระบบใหม่ครั้งแรก หรือได้รับการยืนยัน ชัดเจนแล้วว่าต้องการล้างข้อมูลปัจจุบันทั้งหมดแล้วแทนที่ด้วยไฟล์ที่เพิ่ง export มา
  4. เลือกไฟล์ .json ที่ export มาจากขั้นตอนที่ 1 แล้วรอระบบประมวลผลจนขึ้นข้อความแจ้งผลสำเร็จ

หมายเหตุ: บัญชีพนักงาน/คนขับที่มาจากไฟล์เดิมจะมีรหัสผ่านเป็นตัวอักษรธรรมดา (ยังไม่เข้ารหัส) ระบบจะเข้ารหัสให้อัตโนมัติทันทีหลัง import เสร็จ ไม่ต้องทำอะไรเพิ่ม บัญชีเหล่านั้นจะยังล็อกอินด้วยรหัสผ่านเดิมได้ตามปกติ

ผล import ที่ถูกต้องควรขึ้น"สำเร็จ" อย่างเดียว ไม่มีข้อความเตือน ระบบตรวจจับและแก้ปัญหาที่พบได้บ่อยใน ไฟล์ Firebase export ให้อัตโนมัติแล้ว (เช่น เลขอ้างอิงซ้ำกันในไฟล์ต้นฉบับ จะถูกสลับให้ไม่ซ้ำกันเองโดยอัตโนมัติ) ถ้าเจอข้อความเตือนซ้ำ ๆ ทุกครั้งที่ import ให้แจ้งผู้ดูแลระบบ/ผู้พัฒนา อย่าเพิกเฉยไปเรื่อย ๆ เพราะมักแปลว่ามี แถวข้อมูลในไฟล์ต้นฉบับ (Firebase) ที่กรอกไม่ครบจริง ๆ ต้องไปแก้ที่ต้นทาง

เข้าสู่ระบบ

/ , /login

หน้าแรกสุดของระบบ ใช้กรอก User และ Password เพื่อเข้าใช้งาน

วิธีใช้งาน

  • กรอกช่อง User และ Password แล้วกดปุ่ม "เข้าสู่ระบบ"
  • ระบบจะพาไปหน้าที่เหมาะกับสิทธิ์ของบัญชีนั้นโดยอัตโนมัติ: มีสิทธิ์ พขร. อย่างเดียว → ไปหน้าพนักงานขับรถ, มีสิทธิ์ หน้าลานอย่างเดียว → ไปหน้าลงข้อมูลน้ำมัน, นอกนั้น → ไปหน้า "เลือกเมนู"
ไม่มีปุ่ม "ลืมรหัสผ่าน" — หากลืมรหัสผ่านต้องให้ผู้ดูแลระบบช่วยตั้งรหัสใหม่ให้ผ่านหน้าจัดการพนักงาน

เลือกเมนู

/choose

หน้ากลางหลังล็อกอิน รวมทางลัดไปหน้าหลักที่ตรงกับสิทธิ์ของบัญชีนั้น ๆ ให้เลือกเข้า

ปุ่ม/การ์ดที่อาจเห็น (แสดงตามสิทธิ์)

  • "หน้าหลัก" — แสดงเมื่อมีสิทธิ์อย่างน้อย 1 อย่างจาก 6 สิทธิ์หลัก กดแล้วพาไปหน้าที่เหมาะกับสิทธิ์แรงสุดของบัญชี (มี BasicData → หน้า Dashboard, ไม่มีแต่มีรถเล็ก → หน้าจัดเที่ยววิ่งรถเล็ก, ไม่มีแต่มีปฏิบัติงาน → เที่ยววิ่งรถใหญ่, ไม่มีแต่มีการเงิน → ชำระค่าน้ำมัน, ไม่มีแต่มีรายงาน → หน้าชำระค่าขนส่ง)
  • "พนักงานขับรถ" — แสดงเมื่อมีสิทธิ์ พขร. ควบคู่กับสิทธิ์อื่น (ไม่ใช่บัญชีคนขับรถโดยตรง) กดแล้วไปหน้าจัดการ/ติดตามเที่ยววิ่งของพนักงานขับรถ
  • "ใบเสนอราคาลูกค้า" — แสดงให้ทุกคนเสมอ ไม่ขึ้นกับสิทธิ์ใด ๆ

ส่วนเครื่องมือผู้ดูแลระบบ (แสดงเฉพาะมีสิทธิ์ AdminData)

  • ปุ่ม "นำเข้าข้อมูล JSON (ทับข้อมูลเดิมทั้งหมด)" และ "เพิ่มข้อมูลใหม่ (ไม่ลบของเดิม)" — ดูรายละเอียดในหมวดผู้ดูแลระบบด้านล่าง
  • ปุ่ม "สำรองข้อมูล" — เปิดกล่องให้ยืนยันรหัสผ่านก่อนเข้าหน้าสำรองข้อมูล (ดูหมวดผู้ดูแลระบบ)

ใบเสนอราคาลูกค้า

/quotation

สร้าง แก้ไข และพิมพ์เอกสารใบเสนอราคาน้ำมันให้ลูกค้า เปิดให้ทุกบัญชีใช้ได้เสมอ ไม่ผูกกับสิทธิ์ใดเลย

ส่วนประกอบหลัก

  • หน้าสร้างใบเสนอราคาใหม่ — ติ๊กเลือกประเภท "รถใหญ่" หรือ "รถเล็ก" แล้วกรอกรายละเอียด
  • ปุ่ม "ตรวจสอบใบวางบิลที่เคยกรอกข้อมูล" — สลับไปหน้ารายการใบเสนอราคาที่มีอยู่แล้ว เพื่อดู/แก้ไข/ยกเลิก

ในหน้าแก้ไขรายการที่มีอยู่

  • "แก้ไข" — เปิดแก้ไขรายละเอียดใบเสนอราคา
  • "พิมพ์ใบเสนอราคาลูกค้า" — ส่งออกเป็น PDF ทันทีในเบราว์เซอร์ (ไม่ต้องเปิดหน้าต่างพิมพ์แยก)
  • "ยกเลิก" — ยกเลิกใบเสนอราคานั้น
  • "กลับไปยังหน้าสำหรับเพิ่มข้อมูล" — กลับไปหน้าสร้างใหม่

ตั้งค่า — ข้อมูลส่วนตัว

/setting

ทุกบัญชีเข้าดูข้อมูลของตัวเองและเปลี่ยนรหัสผ่านได้ที่แท็บนี้เสมอ (อีก 2 แท็บของหน้านี้สงวนไว้เฉพาะผู้ดูแลระบบ — ดูหมวดผู้ดูแลระบบด้านล่าง)

สิ่งที่ทำได้

  • ดูข้อมูล ชื่อ-สกุล ตำแหน่ง User เบอร์โทร ของตนเอง
  • กดปุ่ม "แก้ไขรหัสผ่าน" → กรอกรหัสผ่านเดิม รหัสผ่านใหม่ ยืนยันรหัสผ่านใหม่ แล้วกด "บันทึก"
  • ไอคอน ⓘ ข้าง "ตำแหน่ง" อธิบายว่าสิทธิ์การใช้งานผูกกับตำแหน่งนี้ หากต้องการเปลี่ยนสิทธิ์ให้ติดต่อผู้ดูแลระบบ

🔑 ข้อมูลทั่วไป

สิทธิ์ BasicData

กลุ่มสิทธิ์ที่กว้างที่สุด ครอบคลุมข้อมูลพื้นฐานของกิจการทั้งหมด 13 หน้า — ข้อมูลพนักงาน รถ ลูกค้า และคู่ค้าต่าง ๆ ที่หน้าอื่น ๆ ในระบบดึงไปใช้ต่อ ผู้ที่มีสิทธิ์นี้จะเห็นเมนู "ข้อมูลทั่วไป" ในแถบด้านข้าง

หน้าหลัก

/dashboard

ภาพรวมกิจการแบบสรุปในหน้าเดียว ใช้ดูตัวเลขสำคัญและแนวโน้มธุรกิจแบบเร็ว ๆ

ส่วนประกอบหลัก

  • การ์ดสรุปตัวเลข 6 ใบ (รถบรรทุก, ลูกค้า, ปั้มน้ำมัน, เที่ยววิ่งรถใหญ่, ใบแจ้งหนี้, ตั๋วน้ำมัน) — กดที่การ์ดเพื่อลิงก์ตรงไปหน้านั้น ๆ ได้ทันที
  • กราฟแนวโน้มยอดขายรายเดือน พร้อมตัวเลือกวันที่และปุ่มล้างตัวกรอง
  • กราฟวงกลมสรุปสัดส่วนตั๋วน้ำมันแต่ละประเภท
เป็นหน้าสรุปอย่างเดียว ไม่มีการเพิ่ม/แก้ไขข้อมูลใด ๆ ในหน้านี้

พนักงาน

/employee

ทะเบียนพนักงานทั้งหมด ทั้งพนักงานบริษัทและพนักงานขับรถ พร้อมข้อมูลเงินเดือนและตำแหน่ง

สิ่งที่ทำได้

  • สลับดูระหว่างแท็บ พนักงานขับรถ และ พนักงานบริษัท
  • ปุ่ม "เพิ่มพนักงาน" เปิดฟอร์มกรอกข้อมูลใหม่ (รวมถึงกำหนด User/Password และตำแหน่งงาน)
  • คลิกแถวเพื่อดู/แก้ไขข้อมูลพนักงานแต่ละคน
  • ไอคอน ⓘ อธิบายความหมายของคอลัมน์ที่อาจไม่คุ้นเคย เช่น ประเภทรถที่ผูกกับคนขับ

รถบรรทุก

/trucks

ทะเบียนรถบรรทุกของบริษัทเอง ทั้งรถใหญ่ (หัว-หาง) และรถเล็ก พร้อมรายการตรวจสอบสภาพรถ

แท็บภายในหน้า

  • รถใหญ่ / หางรถ — ข้อมูลรถหัว-หางแยกกัน เพราะจับคู่ใช้งานได้หลายแบบ
  • รถเล็ก — ทะเบียนรถเล็กของบริษัท

สิ่งที่ทำได้

  • เพิ่ม/แก้ไขทะเบียนรถในแต่ละแท็บ
  • ปุ่ม "รายการตรวจสอบสภาพรถ" สลับไปดูเฉพาะรถที่ยังไม่ผ่านการตรวจสภาพ

รถรับจ้างขนส่ง

/trucks-transport

ทะเบียนรถบรรทุกของ "บริษัทรับจ้างขนส่ง" ภายนอก ที่มาวิ่งงานให้ (ไม่ใช่รถของบริษัทเอง)

สิ่งที่ทำได้

  • เพิ่ม/แก้ไขทะเบียนรถรับจ้าง ผูกกับบริษัทขนส่งที่เป็นเจ้าของรถ ใช้เป็นข้อมูลตั้งต้นตอนจัดเที่ยววิ่งรถรับจ้าง

คลังรับน้ำมัน

/depots

รายชื่อคลัง/โซนรับน้ำมัน (เช่น ลำปาง, พิจิตร, สระบุรี, บางปะอิน, IR) ที่ใช้อ้างอิงอัตราค่าขนส่งตามระยะทาง

สิ่งที่ทำได้

  • เพิ่ม/แก้ไข/ลบ (ปิดใช้งาน) รายชื่อคลังรับน้ำมัน — หน้านี้เป็นข้อมูลอ้างอิงที่หน้าตั๋วต่าง ๆ ดึงไปใช้คำนวณราคาต่อโซน

ตั๋วน้ำมัน

/ticket

ทะเบียนลูกค้า "ตั๋วน้ำมัน" ของรถใหญ่ที่ไม่ใช่ลูกค้าประจำ/ไม่ใช่รถรับจ้าง พร้อมเงื่อนไขราคา/เครดิตต่อราย

สิ่งที่ทำได้

  • เพิ่ม/แก้ไขข้อมูลลูกค้าตั๋วน้ำมัน (ที่อยู่, ระยะเวลาเครดิต, สถานะ)
  • ไอคอน ⓘ อธิบายคอลัมน์ประเภทรถและอัตราค่าขนส่งต่อคลัง

ลูกค้ารับจ้างขนส่ง

/transports

ทะเบียนลูกค้าที่ใช้บริการแบบ "รับจ้างขนส่ง" (ใช้รถของบริษัทรับจ้างภายนอกวิ่งให้)

สิ่งที่ทำได้

  • เพิ่ม/แก้ไขข้อมูลลูกค้ากลุ่มรับจ้างขนส่ง, ตั้งเงื่อนไขราคา/เครดิตเช่นเดียวกับตั๋วน้ำมัน

ลูกค้ารถใหญ่

/customer-bigtrucks

ทะเบียนลูกค้าประจำที่ใช้รถใหญ่ของบริษัทเองขนส่งให้ (แยกจาก "ตั๋วน้ำมัน" ที่เป็นลูกค้าจร)

สิ่งที่ทำได้

  • เพิ่ม/แก้ไขข้อมูลลูกค้า มีแท็บแยกโซน (เชียงใหม่/เชียงราย) ตามพื้นที่ให้บริการ
  • คลิกชื่อตั๋วเพื่อดูรายละเอียดเพิ่มเติม, ไอคอน ⓘ อธิบาย "อยู่บริษัทในเครือ", "ลูกค้าประจำ", "วางบิลด้วย" และอัตราค่าขนส่งต่อคลัง

ลูกค้ารถเล็ก

/customer-smalltrucks

ทะเบียนลูกค้าที่ใช้บริการรถเล็กของบริษัท เทียบเท่าหน้าลูกค้ารถใหญ่แต่สำหรับรถเล็ก

สิ่งที่ทำได้

  • เพิ่ม/แก้ไขข้อมูลลูกค้ารถเล็ก, ตั้งรอบวางบิล/เครดิต/สถานะ พร้อมไอคอน ⓘ อธิบายฟิลด์ที่ไม่คุ้นเคย

เจ้าหนี้น้ำมัน

/creditor

รายชื่อบริษัทที่บริษัทเราซื้อน้ำมันมาจาก (ไม่ใช่ลูกค้า — เป็นคู่ค้าฝั่งต้นทาง)

สิ่งที่ทำได้

  • เพิ่ม/แก้ไขข้อมูลเจ้าหนี้น้ำมันและระยะเวลาเครดิตที่ได้รับจากเจ้าหนี้แต่ละราย
ชื่อหน้านี้ทำให้สับสนได้ง่าย — "เจ้าหนี้" ในที่นี้คือคนที่เราซื้อของจาก ไม่ใช่ลูกค้าที่ค้างเงินเรา

รายได้รายหัก

/deductible-income

บัญชีรายชื่อ "รายการ" รายได้เสริม/รายการหักเงินที่ใช้ประกอบการคำนวณเงินเดือนพนักงาน (เป็นตัวเลือกตั้งต้น ไม่ใช่การกรอกยอดจริงรายเดือน — การกรอกยอดจริงทำที่หน้า "ค่าใช้จ่าย" ในหมวดรายงาน/การเงิน)

สิ่งที่ทำได้

  • ติ๊กเลือกแสดงเฉพาะ "รายได้" หรือ "รายหัก" หรือทั้งคู่
  • เพิ่ม/แก้ไข/ปิดใช้งานรายการ พร้อมกำหนดว่าเป็นรายการ "ประจำ" (เกิดทุกงวด) หรือไม่

รายการค่าใช้จ่าย

/expense-items

บัญชีรายชื่อประเภทค่าใช้จ่ายของกิจการ (ใช้เป็นตัวเลือกตั้งต้นตอนบันทึกบิลค่าใช้จ่ายจริง)

สิ่งที่ทำได้

  • เพิ่ม/แก้ไข/ปิดใช้งานประเภทค่าใช้จ่าย

บริษัทที่สั่งจ่าย

/company-payment

บัญชีรายชื่อบริษัท/นิติบุคคลที่ใช้เป็นผู้จ่ายเงินในเอกสารการเงินต่าง ๆ

สิ่งที่ทำได้

  • เพิ่ม/แก้ไข/ปิดใช้งานรายชื่อบริษัทที่สั่งจ่าย

งานหน้างานของฝ่ายปฏิบัติการ — บันทึกสต็อกหน้าลานรายวัน ดูรายงานสต็อก และจัดเที่ยววิ่งของรถใหญ่/รถรับจ้างขนส่ง

สต็อกหน้าลาน

/gasstations

จุดบันทึกข้อมูลสต็อกน้ำมันหน้าลานประจำวัน และจัดการบัญชีรายชื่อปั้ม/คลังสต็อก

2 โหมดของหน้านี้ (สลับด้วยปุ่มไอคอนด้านบน)

  • ปั้มน้ำมัน — เลือกวันที่ (ปกติคือวันนี้) และตัวกรองคลัง แล้วกรอกปริมาณ/ผลิตภัณฑ์ของแต่ละปั้มในวันนั้น กดบันทึกเพื่อยืนยัน
  • คลังสต็อกน้ำมัน — จัดการรายชื่อคลังและผลิตภัณฑ์/ความจุถังของแต่ละคลัง (ไอคอนรูปเฟืองเพื่อแก้ไข, ปุ่ม "เพิ่มผลิตภัณฑ์")

ปุ่มหลัก

  • "เพิ่มปั้มน้ำมัน" / "เพิ่มคลังสต็อกน้ำมัน" (ข้อความเปลี่ยนตามโหมดที่เลือก) — เปิดฟอร์มเพิ่มรายการใหม่
ถ้าแก้ไขข้อมูลค้างไว้แล้วพยายามเปลี่ยนวันที่หรือเปลี่ยนคลังทันที ระบบจะเตือนให้ บันทึกก่อน ไม่งั้นการเปลี่ยนจะถูกยกเลิก ตัวเลขบางช่องที่ขึ้นให้อัตโนมัติ (ดึงจากเมื่อวาน) ก็ยังไม่ถูกบันทึกจริงจนกว่าจะกดบันทึก

รายงานสต๊อก

/report-gasstations

ตารางเทียบยอดสต็อกในระบบกับเลขมิเตอร์หน้าปั้มจริง (CBP) รายวันตลอดทั้งเดือน ต่อปั้ม ต่อผลิตภัณฑ์ ใช้หาส่วนต่างที่ขาด/เกิน

วิธีใช้งาน

  • เลือก ปี และ เดือน ที่ต้องการ แล้วเลือกกรองคลัง/ปั้ม
  • แต่ละแถวผลิตภัณฑ์กรอกเลขมิเตอร์ (CBP) ของแต่ละวันได้ในตารางเดียวกัน แล้วกด "บันทึก CBP"
  • ปั้มที่มีของขาย "หลังร้าน" (Backyard) จะมีตารางย่อยแยกให้กรอก CBP ต่างหาก
หน้านี้เป็นทั้งรายงานและช่องกรอกข้อมูลในตารางเดียวกัน — ไม่มีโหมด "ดูอย่างเดียว" แยกจากโหมด "กรอกข้อมูล"

เที่ยววิ่งรถใหญ่

/trips-bigtruck

รายการเที่ยววิ่งของรถใหญ่และรถรับจ้างขนส่งทั้งหมด เป็นจุดเริ่มจัดเที่ยววิ่งใหม่และติดตามเที่ยวที่กำลังวิ่งอยู่

ตัวกรอง

  • ช่วงวันที่รับ (ค่าเริ่มต้น: เดือนปัจจุบัน)
  • สถานะ: ทั้งหมด / กำลังจัดเที่ยววิ่ง (ค่าเริ่มต้น) / ยกเลิก / จบทริป

สิ่งที่ทำได้

  • ปุ่ม "เพิ่มเที่ยววิ่ง" เปิดฟอร์มจัดเที่ยววิ่งใหม่ (เลือกรถ คนขับ คลัง และปลายทางได้สูงสุด 8 จุดส่ง)
  • คลิกที่แถวเพื่อดูรายละเอียด แก้ไขจุดส่งแต่ละจุด หรือกด "จบทริป" — ทำที่ท้ายแถวของแต่ละเที่ยว ไม่มีปุ่มแยกต่างหาก

งานฝ่ายการเงินฝั่งรถใหญ่ — ติดตามเงินที่ลูกค้าต้องโอนเข้า และออกใบวางบิลให้ลูกค้ารับจ้างขนส่ง เมนูด้านข้างมีให้กด 2 หน้า ส่วนอีก 2 หน้าด้านล่างเปิดได้จากลิงก์ตรง/แถบไอคอนย่อเท่านั้น (ไม่ได้อยู่ในเมนูขยายหลัก)

ชำระค่าน้ำมัน

/invoice

ติดตามยอดค้างชำระค่าน้ำมันของลูกค้าตั๋วรถใหญ่ และบันทึกยอดเงินโอนเข้าจริง

ตัวกรอง

  • สถานะลูกค้า: ทั้งหมด / อยู่บริษัทในเครือ / ไม่อยู่บริษัทในเครือ
  • ช่วงวันที่ส่ง และติ๊ก "ค้างโอน" เพื่อดูเฉพาะรายการที่ยังไม่ครบยอด (ติ๊กนี้จะยกเลิกตัวกรองวันที่ชั่วคราว)

สิ่งที่ทำได้

  • คลิกชื่อลูกค้า/ตั๋วในตาราง เพื่อเปิดฟอร์มบันทึกยอดโอนด้านล่างตาราง — กรอกวันที่โอน ธนาคาร และยอดเงิน
ตารางแสดงเฉพาะรายการตั้งแต่ 1 ม.ค. 2569 เป็นต้นไป (ข้อมูลก่อนหน้านั้นเป็นข้อมูลย้ายระบบเก่า จะไม่แสดงในหน้านี้)

ชำระค่าขนส่ง (ใบวางบิลรถรับจ้างขนส่ง)

/report

ออกใบวางบิลให้บริษัทที่ต้องจ่ายค่าขนส่ง แยกยอดตามแต่ละบริษัทในตั๋วเดียวกันได้ พร้อมกำหนดวันครบกำหนดชำระ

วิธีใช้งาน

  • เลือกกลุ่มตั๋ว/ลูกค้าที่ต้องการออกบิล จะเห็นตารางรายการที่รอวางบิล แยกเป็น 2 บริษัทถ้าตั๋วนั้นมีเจ้าของร่วม
  • ก่อนกด "พิมพ์ใบวางบิล" เลือกได้ว่ากำหนดชำระเงินจะเป็นแบบ "ตามที่กำหนดไว้" (คำนวณจากระยะเวลาเครดิตของตั๋วนั้นอัตโนมัติ) "กำหนดเอง" (เลือกวันที่เอง) หรือ "ไม่ระบุวันที่"
  • ปุ่ม "NEW" รีเซ็ตเลขที่/วันที่วางบิลของกลุ่มนั้นใหม่
  • กด "พิมพ์ใบวางบิล" เพื่อเปิดหน้าต่างพิมพ์เอกสารใบวางบิล

บิลค่าใช้จ่าย

/invoice-financial

บันทึกบิลค่าใช้จ่ายต่าง ๆ ของรถ (ผูกกับทะเบียนรถ บริษัท และบัญชีธนาคารที่จ่าย) พร้อมแนบไฟล์ใบเสร็จ

สิ่งที่ทำได้

  • ติ๊กกรอง ทั้งหมด / เดี่ยว / กลุ่ม (บิลกลุ่มคือบิลที่มีธนาคาร+บริษัท+เลขที่บิลตรงกันหลายรายการ ถูกรวมยอดเป็นแถวเดียว)
  • ปุ่ม "เพิ่มบิล" — กรอกบริษัท บัญชีธนาคาร ประเภทเดี่ยว/กลุ่ม ทะเบียนรถ และแนบไฟล์
  • คลิกแถวเพื่อแก้ไขบิล, ไอคอนถังขยะเพื่อยกเลิกบิล
  • Export to Excel ออกรายงานบิลตามช่วงวันที่
ไอคอนถังขยะไม่ได้ลบข้อมูลจริง แค่เปลี่ยนสถานะเป็น "ยกเลิก" แล้วซ่อนออกจากรายการ; บิลประเภท "กลุ่ม" ยกเลิกทีละรายการไม่ได้ (ปุ่มถูกปิดใช้งาน) ต้องหน้านี้เข้าได้อีกทางผ่านแท็บ "บิลค่าใช้จ่าย" ในหน้า "ค่าใช้จ่าย" (หมวดรายงาน) ด้วย เป็นหน้าจอเดียวกันทุกประการ

รายได้รายหัก (บันทึกยอดจริง)

/financial-deduction

กรอกยอดรายได้เสริม/รายการหักเงินจริงของพนักงานแต่ละคนในแต่ละงวดจ่ายเงินเดือน โดยเลือกจากรายการที่ตั้งไว้ในหน้า "รายได้รายหัก" (หมวดข้อมูลทั่วไป)

สิ่งที่ทำได้

  • เลือก ปีงวดการจ่าย และ ลำดับงวด ระบบแสดงช่วงวันที่ของงวดนั้นให้อัตโนมัติ
  • ปุ่ม "เพิ่มรายได้รายหัก" — เลือกพนักงาน เลือกว่าเป็นรายได้หรือรายหัก แล้วเลือกรายการ เพิ่มได้หลายรายการพร้อมกัน
  • ไอคอนถังขยะยกเลิกรายการ, Export to Excel ออกรายงานของงวดนั้น
เช่นเดียวกับบิลค่าใช้จ่าย การ "ลบ" ที่นี่คือเปลี่ยนสถานะเป็นยกเลิกเท่านั้น และหน้านี้เข้าได้อีกทางผ่านแท็บ "รายได้รายหัก" ในหน้า "ค่าใช้จ่าย" (หมวดรายงาน)

รายงานสรุปฝั่งรถใหญ่ทั้งหมด 8 หน้า ส่วนใหญ่เป็นรายงานดูอย่างเดียว + ส่งออก Excel มีบางหน้าที่แก้ไขข้อมูลได้ในตัว

รายงานหลายหน้าในหมวดนี้ (ชำระค่าน้ำมัน, สรุปค่าเที่ยว, เงินเดือน, กำไรขายส่งน้ำมัน) แสดงเฉพาะข้อมูลตั้งแต่ 1 มกราคม 2569 เป็นต้นไปเท่านั้น เป็นข้อจำกัดของระบบ ไม่ใช่ตัวกรองที่ปรับได้

  • หัวคอลัมน์วันที่ส่ง/ผู้ขับ-ป้ายทะเบียน/ตั๋ว กดเพื่อเรียงลำดับได้

  • Export to Excel ออกรายงานค่าเที่ยวของคนขับที่เลือก

การชำระค่าน้ำมัน

/report-fuel-payment

รายงานสรุปยอดค้างชำระของลูกค้าตั๋วรถใหญ่ทุกราย เทียบยอดบิลกับยอดโอนจริง (เป็นรายงานคู่กับหน้า "ชำระค่าน้ำมัน" ในหมวดการเงิน)

ตัวกรอง / ปุ่ม

  • สถานะ: ทั้งหมด / อยู่บริษัทในเครือ / ไม่อยู่บริษัทในเครือ + ช่วงวันที่
  • ไอคอนท้ายแถวเปิดกล่อง "ตรวจสอบข้อมูลรายงานการชำระค่าน้ำมัน" ดูรายละเอียดการโอนของตั๋วนั้น พร้อมปุ่ม "บันทึกเป็น PDF"
  • Export to Excel และแถบสรุปยอดรวม/ยอดโอน/ค้างโอนท้ายตาราง

การชำระค่าขนส่ง

/report-transport-payment

รายงานสรุปยอดที่ต้องจ่ายให้รถรับจ้างขนส่งแต่ละราย ต่องวดการจ่าย หักภาษี ณ ที่จ่าย 1% ให้อัตโนมัติ

ตัวกรอง

  • เลือก ปี และ เดือน ของงวดจ่าย (มีปุ่ม ▲▼ เลื่อนเดือนได้), เลือกบริษัท, ติ๊กประเภทตั๋วที่ต้องการ (ตั๋วน้ำมัน/ตั๋วปั้ม/ตั๋วรับจ้างขนส่ง)
อัตราค่าขนส่งต่อลิตรไม่เท่ากันทุกตั๋ว — ขึ้นกับคลังที่ไปรับน้ำมัน (ลำปาง/พิจิตร/สระบุรี-บางปะอิน-IR ใช้อัตราคนละชุด) ระบบเลือกอัตราให้อัตโนมัติตามคลังของแต่ละเที่ยว

ค่าใช้จ่าย

/expenses

หน้ารวมทางลัดไปหน้าบันทึกค่าใช้จ่าย 2 แบบ สำหรับผู้ที่มีสิทธิ์รายงาน (แทนที่จะต้องมีสิทธิ์การเงินโดยตรง)

แท็บภายในหน้า

  • รายได้รายหัก — เหมือนหน้า "รายได้รายหัก (บันทึกยอดจริง)" ในหมวดการเงินทุกประการ
  • บิลค่าใช้จ่าย — เหมือนหน้า "บิลค่าใช้จ่าย" ในหมวดการเงินทุกประการ

เงินเดือน

/salary

สรุปเงินเดือนพนักงานขับรถต่องวด รวมค่าเที่ยวที่ทำได้จริงเข้ากับรายได้/รายหักทุกรายการที่บันทึกไว้ พร้อมยอดเงินค้ำประกัน/เงินกู้ยืมสะสม

วิธีใช้งาน

  • เลือกปีและลำดับงวดจ่าย, ค้นหาด้วยชื่อ/ทะเบียนได้
  • ไอคอนท้ายแถวเปิดดูประวัติ "ยอดสะสมเงินค้ำประกัน" หรือเงินกู้ยืมของพนักงานคนนั้น พร้อม Export Excel และปุ่มบันทึก/ยกเลิกของตัวเอง
  • Export to Excel ออกรายงานเงินเดือนทั้งงวด
ค่าเที่ยวที่นับในเงินเดือนนับเฉพาะเที่ยวที่สถานะ "จบทริป" แล้วภายในงวดนั้นเท่านั้น เที่ยวที่ยังไม่จบจะไม่ถูกนับ

ปิดงบบัญชีการเงิน

/close-financial

งบกำไรขาดทุนของแต่ละคนขับ/รถ ต่อเดือนหรือต่อปี เทียบรายได้ (ตั๋วน้ำมัน/ตั๋วรับจ้างขนส่ง/ตั๋วปั้ม) กับค่าใช้จ่ายทุกประเภท จบด้วยยอดกำไรสุทธิ

ตัวกรอง

  • ติ๊กเลือก รายปี หรือ รายเดือน แล้วเลือกช่วงเวลา, เลือกบริษัทที่ต้องการดู
  • ติ๊กเลือกแสดงผลแบบ ค่าขนส่ง หรือ จำนวนลิตร
เป็นรายงานดูอย่างเดียว (ไม่มีปุ่ม "ปิดงบ" จริง ๆ ในหน้านี้) ต้องเลือกทั้งงวดเวลาและบริษัทก่อนตัวเลขจึงจะแสดงครบ

กำไรขายส่งน้ำมัน

/profit-loss

กำไร/ขาดทุนต่อรายการขายน้ำมันแต่ละเที่ยว เทียบราคาขาย ราคาทุน และค่าขนส่ง พร้อมแก้ไขราคาทุนได้ในตาราง

สิ่งที่ทำได้

  • สลับมุมมอง ราคา/ลิตร หรือ จำนวนเงินรวม
  • คลิกที่ช่อง "ราคาทุน/ลิตร" ของแต่ละแถวเพื่อกรอก/แก้ไขราคาทุนได้ทันที แล้วกดติ๊กถูกสีเขียวเพื่อบันทึก
  • Export to Excel
ติ๊ก "บริษัทในเครือ" ของหน้านี้สลับความหมายที่อาจเข้าใจผิดได้ — ค่าเริ่มต้น (ติ๊กอยู่) จะโชว์ลูกค้าที่ไม่ได้อยู่บริษัทในเครือ ลองสลับดูถ้าหาแถวที่ต้องการไม่เจอ

🚐 รถเล็ก

สิทธิ์ SmallTruckData

ชุดหน้าจอฝั่งรถเล็กทั้ง 7 หน้า ทำหน้าที่เทียบเท่าหมวด "ปฏิบัติงาน + การเงิน + รายงาน" ของรถใหญ่ แต่รวบเป็นสิทธิ์เดียวและเมนูเดียว

จัดเที่ยววิ่ง

/trips-smalltruck

รายการเที่ยววิ่งของรถเล็กทั้งหมด เทียบเท่าหน้า "เที่ยววิ่งรถใหญ่" ของฝั่งรถใหญ่

ตัวกรอง / ปุ่ม

  • ช่วงวันที่รับ-ส่ง (ค่าเริ่มต้น: เดือนปัจจุบัน)
  • สถานะ: ทั้งหมด / กำลังจัดเที่ยววิ่ง (ค่าเริ่มต้น) / ยกเลิก / จบทริป
  • ปุ่มเพิ่มเที่ยววิ่งใหม่ที่มุมขวาบน, คลิกแถวเพื่อดูรายละเอียด/แก้ไข/กดจบทริป

ชำระค่าน้ำมัน

/invoice-smalltruck

ติดตามยอดค้างชำระของลูกค้ารถเล็ก และบันทึกยอดโอนเข้าจริง (เทียบเท่าหน้า "ชำระค่าน้ำมัน" รถใหญ่)

สิ่งที่ทำได้

  • กรองสถานะ อยู่/ไม่อยู่บริษัทในเครือ, ช่วงวันที่, ติ๊ก "ค้างโอน" ดูเฉพาะรายการค้าง
  • คลิกชื่อลูกค้าเพื่อเปิดฟอร์มบันทึกยอดโอนด้านล่างตาราง

สรุปยอดน้ำมัน

/oil-balance-smalltruck

รายงานยอดขายน้ำมันของรถเล็กที่จัดส่งสำเร็จแล้ว แยกตามคนขับ/ตั๋ว/ชนิดน้ำมัน

ตัวกรอง / ปุ่ม

  • ช่วงวันที่ และเลือกตั๋วเฉพาะราย (หรือแสดงทั้งหมด)
  • Export to Excel พร้อมยอดรวมลิตร/ยอดเงินท้ายหน้า

รายงานชำระน้ำมัน

/payment-smalltruck

รายงานสรุปยอดค้างชำระของลูกค้ารถเล็กทุกราย (คู่กับหน้า "ชำระค่าน้ำมัน" รถเล็ก) พร้อมดูรายละเอียดรายตั๋ว

สิ่งที่ทำได้

  • กรองสถานะ/ช่วงวันที่, ไอคอนท้ายแถวเปิดดูรายละเอียดรายการโอน
  • Export to Excel พร้อมสรุปยอดลิตร/ยอดเงิน/ยอดโอน/ค้างโอนท้ายตาราง

รายงานเที่ยววิ่ง

/report-smalltruck

รายงานเดินบัญชีน้ำมันของรถเล็กแต่ละคัน (รับเข้า-ส่งออก-ยอดยกมา) และเป็นจุดเริ่มออกใบวางบิลให้ลูกค้ารถเล็ก

วิธีใช้งาน

  • เลือกช่วงวันที่และรถขนส่งที่ต้องการดู (หรือแสดงทั้งหมด)
  • ตารางแสดงยอดรับเข้า/ส่งออกต่อวัน แยกตามชนิดน้ำมัน พร้อมยอดยกมาและยอดคงเหลือ
  • เปิดเข้าไปในกลุ่มตั๋วเพื่อออกใบวางบิล — ก่อนพิมพ์เลือกได้ว่ากำหนดชำระเงินแบบตามที่กำหนดไว้/กำหนดเอง/ไม่ระบุวันที่ เหมือนหน้าออกบิลรถใหญ่
  • Export to Excel
ปริมาณน้ำมันของรถเล็กในหน้านี้เป็นหน่วยลิตรอยู่แล้ว ไม่ต้องคูณ 1000 เหมือนตัวเลขฝั่งรถใหญ่ — อย่าตกใจถ้าตัวเลขดูน้อยกว่าที่คุ้นเคย

ปิดงบบัญชีการเงิน

/close-financial-smalltruck

งบกำไรขาดทุนต่อรถเล็กแต่ละคัน เทียบรายได้ (ค่าขนส่ง+กำไร) กับค่าใช้จ่ายทุกประเภท เทียบเท่าเวอร์ชันรถใหญ่

ตัวกรอง

  • ติ๊กเลือกรายปี/รายเดือนแล้วเลือกช่วงเวลา, Export to Excel

กำไรขายส่งน้ำมัน

/profit-loss-smalltruck

กำไร/ขาดทุนต่อรายการขายของรถเล็กแต่ละเที่ยว พร้อมแก้ไขราคาทุนได้ในตาราง

สิ่งที่ทำได้

  • สลับมุมมองราคา/ลิตร หรือจำนวนเงินรวม, ติ๊กกรองบริษัทในเครือ
  • คลิกช่อง "ราคาทุน/ลิตร" ในแถวเพื่อกรอก/แก้ไขราคาทุนได้ทันที แล้วกดบันทึก
  • Export to Excel

สิทธิ์ GasStationData

ลงข้อมูลน้ำมันหน้าลาน

/gasstation-attendant

หน้าจอเฉพาะของพนักงานหน้าลาน ใช้บันทึกยอดน้ำมันรับเข้า/จ่ายออกของปั้มที่ตนเองประจำอยู่ ในแต่ละวัน

  • "ออกจากระบบ" (มุมขวาบน, มีถามยืนยันก่อนออก)

🚚 พนักงานขับรถ

สิทธิ์ DriverData

บัญชีที่มี เฉพาะ สิทธิ์นี้อย่างเดียวจะถูกพาเข้าหน้าพอร์ทัลส่วนตัวทันที (ไม่เห็นเมนูหลัก) ส่วนบัญชีที่มีสิทธิ์นี้ร่วมกับสิทธิ์อื่น (เช่น ฝ่ายปฏิบัติการ) จะเห็นการ์ด "พนักงานขับรถ" ในหน้าเลือกเมนู เพื่อเข้าไปติดตาม/จัดการเที่ยววิ่งของคนขับแทน

หน้าพนักงานขับรถ (ของตัวเอง)

/driver-detail

พอร์ทัลส่วนตัวของคนขับ ดูข้อมูลรถ/เที่ยววิ่งของตัวเอง และอัปเดตสถานะการจัดส่งระหว่างวิ่งงาน

สิ่งที่เห็น

  • ข้อมูลตัวเอง: คำนำหน้า ชื่อ สกุล ตำแหน่ง ทะเบียนหัว/หาง
  • เที่ยววิ่งปัจจุบัน (ถ้ามี) พร้อมรายการจุดส่งทั้งหมดของเที่ยวนั้น

สิ่งที่ทำได้

  • "ตรวจสอบสภาพรถ" — เปิดแบบฟอร์มตรวจเช็คสภาพรถก่อนออกเดินทาง (กดได้ครั้งเดียวต่อเที่ยว)
  • "จัดส่งแล้ว" ต่อแต่ละจุดส่ง — เปิดกล่องแนบรูปภาพหลักฐานการส่ง แล้วกดบันทึกเพื่อปรับสถานะเป็น "จัดส่งสำเร็จ"
  • ไอคอนพิมพ์ต่อแถว — พิมพ์ใบส่งของจุดนั้น
  • "เช็คลำดับในการจัดส่งสินค้า" — เปิด/ปิดแผนผังเส้นทางการวิ่งงาน พร้อมลิงก์เปิด Google Maps นำทางไปแต่ละจุด
  • "ออกจากระบบ" (มุมขวาบน)
เมื่อกด "จัดส่งแล้ว" ครบทุกจุดของเที่ยวนั้น ระบบจะปิดเที่ยววิ่งเป็น "จบทริป" และปลดสถานะรถกลับเป็น "ว่าง" ให้อัตโนมัติ — ไม่มีปุ่ม "จบทริป" แยกให้กดเอง

พนักงานขับรถ (มุมมองผู้ดูแล)

/driver

หน้าเดียวกับข้างบนในเชิงฟังก์ชัน แต่สำหรับผู้ที่มีสิทธิ์ พขร. ควบคู่กับสิทธิ์อื่น ใช้เลือกดู/อัปเดตเที่ยววิ่งของคนขับคนไหนก็ได้ แทนที่จะถูกล็อกไว้ที่ตัวเอง

ต่างจากหน้าของคนขับเองตรงไหน

  • มี Dropdown เลือก "ชื่อพนักงานขับรถ/ทะเบียนรถ" ที่ต้องการดูก่อน จึงจะเห็นเที่ยววิ่งของคนนั้น
  • ปุ่มมุมขวาบนเป็น "กลับหน้าแรก" แทนปุ่มออกจากระบบ
  • ปุ่ม/การทำงานอื่น (ตรวจสอบสภาพรถ, จัดส่งแล้ว, พิมพ์, เช็คเส้นทาง, ปิดทริปอัตโนมัติ) เหมือนกันทุกประการ

🛡️ ผู้ดูแลระบบ

สิทธิ์ AdminData

สิทธิ์นี้ไม่ได้เปิดเมนูใหม่ทั้งหน้า แต่จะเพิ่มปุ่ม/แท็บพิเศษ เข้าไปในหน้าที่มีอยู่แล้ว 2 หน้า (หน้าเลือกเมนู และหน้าตั้งค่า) บวกกับหน้าสำรองข้อมูลที่เข้าถึงได้เฉพาะสิทธิ์นี้เท่านั้น ควรให้เฉพาะผู้ที่ดูแลระบบจริง ๆ เท่านั้น เพราะแก้ไขข้อมูลระดับรากฐานของทั้งระบบได้

เครื่องมือผู้ดูแลระบบ ในหน้าเลือกเมนู

/choose

ปุ่มพิเศษ 3 ปุ่มที่จะโผล่มาในกล่อง "เครื่องมือผู้ดูแลระบบ" ท้ายหน้าเลือกเมนู เมื่อบัญชีมีสิทธิ์ AdminData

ปุ่มที่มี

  • "นำเข้าข้อมูล JSON (ทับข้อมูลเดิมทั้งหมด)" — เลือกไฟล์ Firebase export แล้วระบบจะล้างข้อมูลเดิมทุกตารางแล้วแทนที่ด้วยไฟล์ใหม่ทั้งหมด
  • "เพิ่มข้อมูลใหม่ (ไม่ลบของเดิม)" — เลือกไฟล์ Firebase export แล้วระบบจะเพิ่มเฉพาะแถวที่ยังไม่มีในฐานข้อมูล ข้อมูลเดิมไม่ถูกแตะต้อง
  • "สำรองข้อมูล" — เปิดกล่องให้กรอกรหัสผ่านเข้าหน้าสำรองข้อมูลก่อน (ดูหัวข้อถัดไป)
ปุ่มแรกทำลายข้อมูลเดิมทั้งหมด ควรใช้เฉพาะกรณีตั้งระบบใหม่หรือได้รับคำยืนยันชัดเจนแล้วเท่านั้น ปกติควรใช้ปุ่มที่สอง ("เพิ่มข้อมูลใหม่") เพื่อความปลอดภัย

สำรองข้อมูล

/backup

สำรองฐานข้อมูลทั้งระบบเป็นไฟล์ ดาวน์โหลดเก็บไว้ หรือกู้คืนได้ในภายหลัง เข้าถึงได้ต้องผ่าน 2 ชั้น: มีสิทธิ์ AdminData และกรอกรหัสผ่านเฉพาะของหน้านี้ให้ถูกต้อง

ระบบสำรองข้อมูลอัตโนมัติ

  • ระบบสำรองข้อมูลให้อัตโนมัติทุกวัน เวลา 01:00 น. โดยไม่ต้องทำอะไร
  • เก็บไฟล์สำรองไว้เพียง 30 วันล่าสุด ไฟล์ที่เก่ากว่านั้นจะถูกลบทิ้งให้อัตโนมัติ

สิ่งที่ทำได้ในหน้านี้

  • "สำรองข้อมูลเดี๋ยวนี้" — สั่งสำรองข้อมูลทันทีนอกเวลาปกติ
  • ตารางไฟล์สำรองทั้งหมด (ชื่อไฟล์/ขนาด/วันที่สร้าง) พร้อมปุ่ม "ดาวน์โหลด" และไอคอนลบต่อไฟล์
  • "เปลี่ยนรหัสผ่านสำหรับเข้าหน้านี้" — ต้องกรอกรหัสผ่านเดิมให้ถูกก่อน จึงตั้งรหัสผ่านใหม่ได้ (รหัสผ่านเริ่มต้นของระบบคือ admin แนะนำให้เปลี่ยนทันทีหลังติดตั้งระบบ)
รหัสผ่านของหน้านี้เป็นคนละตัวกับรหัสผ่านล็อกอินส่วนตัว — เป็นรหัสผ่านกลางเฉพาะสำหรับหน้าสำรองข้อมูลเท่านั้น ใครก็ตามที่รู้รหัสนี้และมีสิทธิ์ AdminData จะเข้าได้

ตั้งค่า — จัดการสิทธิ์การใช้งาน

/setting

แท็บนี้ในหน้าตั้งค่าจะมองไม่เห็นเลยสำหรับผู้ที่ไม่มีสิทธิ์ AdminData ใช้กำหนดว่าแต่ละ "ตำแหน่งงาน" เปิดเมนูส่วนไหนได้บ้าง เป็นจุดศูนย์กลางที่ควบคุมทุกอย่างในคู่มือเล่มนี้

วิธีใช้งาน

  • ตารางแสดงตำแหน่งงานทุกตำแหน่งเป็นแถว และสิทธิ์ 9 อย่างเป็นคอลัมน์ — ✓ สีเขียวคือมีสิทธิ์ ✗ สีแดงคือไม่มี
  • กดไอคอน ⓘ ที่หัวคอลัมน์แต่ละอันเพื่อดูคำอธิบายว่าสิทธิ์นั้นเปิดอะไรบ้าง
  • กด "แก้ไข" ท้ายแถวเพื่อเปลี่ยนชื่อตำแหน่งหรือติ๊กสิทธิ์ใหม่ แล้วกด "บันทึก"
  • ไอคอน ➕ มุมขวาบนของตารางเพิ่มตำแหน่งงานใหม่
สิทธิ์ ผู้ดูแลระบบ ที่กำหนดในตารางนี้เอง ก็ควบคุมว่าใครแก้ตารางนี้ได้ — ติ๊กให้ตำแหน่งไหนไปแล้ว คนที่อยู่ตำแหน่งนั้นจะมีสิทธิ์เท่าเทียมกับผู้ดูแลระบบทันที ต้องระวังเป็นพิเศษ (ระบบล็อกฝั่งเซิร์ฟเวอร์ไว้แล้วว่าการเพิ่ม/แก้ไข/ลบตำแหน่งต้องมีสิทธิ์นี้เท่านั้น ไม่ใช่แค่ซ่อนปุ่มไว้เฉย ๆ — บัญชีที่ไม่มีสิทธิ์นี้จะเพิ่มตำแหน่งใหม่ผ่านไอคอน ➕ ไม่ได้เช่นกัน แม้แต่ตอนเพิ่มพนักงานใหม่ในหน้า "พนักงาน" ที่มีปุ่มเพิ่มตำแหน่งแบบด่วนซ่อนอยู่ก็ตาม)

ตั้งค่า — ข้อมูลบริษัท

/setting

แท็บนี้ก็มองไม่เห็นสำหรับผู้ไม่มีสิทธิ์ AdminData เช่นกัน ใช้จัดการข้อมูลนิติบุคคลของบริษัทในเครือที่ใช้พิมพ์บนเอกสารทุกใบ (ใบวางบิล ใบเสนอราคา ฯลฯ)

สิ่งที่ทำได้

  • ดูรายชื่อบริษัททั้งหมด กดไอคอน ⓘ เพื่อเปิดรายละเอียด (ชื่อ, เลขผู้เสียภาษี, ที่อยู่)
  • กด "แก้ไข" ในกล่องรายละเอียดเพื่อเปลี่ยนข้อมูล — ระบบจะบันทึกข้อมูลเดิมเป็นประวัติอัตโนมัติก่อนบันทึกค่าใหม่ทุกครั้งที่มีการแก้ไขจริง
  • ปุ่ม "พิมพ์" ในกล่องรายละเอียดบริษัท

หมายเหตุ: สิทธิ์ "รถใหญ่" (BigTruckData)

ในตารางจัดการสิทธิ์จะเห็นคอลัมน์ "รถใหญ่" (BigTruckData) แยกต่างหาก แต่ปัจจุบันสิทธิ์นี้ไม่ได้เปิดเมนูหรือหน้าใดเป็นพิเศษด้วยตัวเอง — มีผลแค่อย่างเดียวคือช่วยให้การ์ด "หน้าหลัก" ปรากฏในหน้าเลือกเมนู (ร่วมกับสิทธิ์หลักอื่น ๆ) เพจฝั่งรถบรรทุกใหญ่จริง ๆ (ทะเบียนรถ ลูกค้า ตั๋ว) อยู่ภายใต้สิทธิ์ ข้อมูลทั่วไป ทั้งหมด ไม่ใช่สิทธิ์นี้
